# Training and throughput qualification

This protocol was fixed before training and held-out evaluation. Run the qualification on the native 3D solver through the public Gymnasium tissue environment. Both the target generator and evaluated methods use the same solver, decision times, measurements and hold scorer. Each episode lasts 1.0 simulation time unit with decisions every 0.125 units.

## Learning

Use a box from (−4, −4, −4) to (4, 4, 4), with two separated cuboids centered at x = −1.5 and 1.5. For each seed, NumPy PCG64 draws independent scale factors uniformly from [0.85, 1.15] for the three side lengths (1.3, 0.85, 0.7) of each cuboid. The two bodies grow in one zone. Volume stiffness is 2, surface tension is 0.01, division and death are disabled, and the target volume ceiling is 10. Maximum integration step is 0.02. Initial geometry changes with seed. Both the reference and every evaluated method start from the same geometry for that seed.

Generate a reference time series for each seed using the known constant growth rate 0.73 volume units per time unit, within the declared bounds [0, 2]. The fixed default rate is 0.15. Target generation is shared setup and excluded from both search budgets. The trainer receives episode rewards. The known generating rate is used solely for reference simulation.

Use training seeds 101, 113 and 127 for all candidates. Fit a deterministic feedback policy with two weights. At every decision its action is 2 × sigmoid(b + k × log(current median volume / reset median volume)). Direct policy search optimizes both weights on complete trajectories. Use the Nelder–Mead simplex (bias, gain) = (0, 0.75), (0.5, 0.75), (0, 1.25). Reflection, expansion, contraction and shrink coefficients are respectively 1, 2, 0.5 and 0.5. Freeze the lowest-error policy actually evaluated by the end of 64 candidate evaluations. Random search draws 64 independent fixed growth rates uniformly on [0, 2] with NumPy PCG64 seed 10517 and selects the vector with the lowest mean error on the same three training seeds. Each search receives **192 simulator episodes**, each with the same limit.

Freeze both selections before running any evaluation with held-out seeds **211, 223, 227, 229 and 233**. Score each method once on each seed. Use actual interval durations for the episode error and give each held-out seed equal weight. A solver or worker failure leaves the episode incomplete. Report all missing method–seed scores and withhold the three-way comparison if any are missing. Passing requires the trained mean to be strictly below both baselines. The reference seed, original geometry, controls, selected weights, training candidate scores, held-out interval times/rewards/actions, method scores and comparison are retained. This tests recovery of outcomes in one controlled tissue fixture.

## Throughput

Run a separate batch with four seeds (307, 311, 313, 317), four ready worker processes and one solver thread per worker. Start each batch under one shared 30-second readiness deadline. Use the same tissue, 1.0 duration and eight intervals; set maximum integration step to 0.0005 for this compute workload. Precompute all eight absolute actions for each seed, drawing uniformly on [0, 2] with PCG64 seeded with 50000 + episode seed. Record control order, interval and time limit alongside the actions.

Compare one active episode at a time with four active episodes. Wall time runs from first reset dispatch to final step return, after readiness and before teardown. Report the sum of actual episode durations divided by this elapsed time, and available CPU affinity. Record reset and step observations and interval end reasons for every seed. Exact-match field names, IDs, sequence lengths and end reasons. Floating observations and times use an absolute tolerance of 1e-10 and relative tolerance of 1e-9; this covers float64 arithmetic noise at the scale of the fixture. Only matched, complete replays qualify the ratio. Preserve the raw elapsed times, simulated durations and earliest mismatch for each failing seed.
